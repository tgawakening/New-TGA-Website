# Private direct uploads: deployment review

Apply the additive migration only after the database owner reviews it and before deploying this branch. Existing receipt and agreement blobs remain unchanged; a non-null storage key selects the new private object.

The server uses `SIRAH_SPACES_ENDPOINT`, `SIRAH_SPACES_REGION`, `SIRAH_SPACES_BUCKET`, `SIRAH_SPACES_KEY`, and `SIRAH_SPACES_SECRET`. Configure `SIRAH_UPLOAD_TOKEN_SECRET` as a separate long random server-side secret. Do not put values in source control. The credentials need permission to create, list, complete and abort multipart uploads, and read private objects.

The Spaces bucket must permit browser CORS `PUT` from the actual registration and classroom origins, including any configured site aliases, and allow `Content-Type` in request headers. Verify a real upload from each deployed origin and a phone before release. Configure a bucket lifecycle rule to abort incomplete multipart uploads. Never apply a blanket expiry rule to `sirah/direct/`, because finalized objects there are referenced by database records. Cancelled or abandoned uploads may leave incomplete multipart uploads, and a finalized object can remain unreferenced if a form is abandoned or its database transaction fails; handling those requires a reference-aware cleanup process.

The presigned part has a 15-minute lifetime and signs the declared byte length. Each upload uses one multipart upload ID. It may be retried or overwritten while that multipart upload is open; the browser immediately asks the server to complete it, which seals it before it is shown as uploaded. After completion the URL can no longer alter the object. The signed claim expires after 30 minutes and is scoped to a purpose, form and actor. Unique database indexes prevent one finalized object being attached twice within its purpose. Registration receipts retain the existing 4 MB JPG/PNG/WebP/PDF content validation. Task attachments allow JPG/PNG/WebP/HEIC/HEIF/PDF/DOC/DOCX up to 25 MB each, five per submission. Agreements allow PDFs up to 5 MB.
